Favorites Sorter

Install Favorites Sorter manually

Use this page if you cannot install the extension from the Chrome Web Store. It works in Chrome, Edge, Brave and other Chromium browsers.

Download the latest version (.zip)

Steps

  1. Unzip the file into a folder you will keep (for example Documents\favorites-sorter). Do not delete the folder afterwards: the browser loads the extension from it.
  2. Open chrome://extensions (in Edge: edge://extensions).
  3. Turn on Developer mode (top right).
  4. Click Load unpacked and choose the folder that contains manifest.json.
  5. Open tiktok.com and sign in: a floating ⇄ Trier mes favoris button appears. Click it, then choose "Importer depuis mon profil TikTok".

Good to know

  • Chrome may show a message about extensions in developer mode when it starts. Keep the extension by dismissing it, or reinstall from the Web Store when it is available.
  • Updates are manual: download the new .zip, replace the folder's content, then click the reload arrow (↻) on the extension card and reload tiktok.com.
  • To use Pro, buy the license on the home page and paste the key in the extension, Settings → License.
  • Your data stays in the browser. Removing the extension deletes it.

The extension automates actions on your TikTok account, which may go against TikTok's terms of service. TikTok may limit, suspend or ban an account. Use it at your own risk. Not affiliated with TikTok.

Installer Trieur de favoris à la main

Utilise cette page si tu ne peux pas installer l'extension depuis le Chrome Web Store. Elle fonctionne sur Chrome, Edge, Brave et les autres navigateurs Chromium.

Télécharger la dernière version (.zip)

Étapes

  1. Décompresse le fichier dans un dossier que tu garderas (par exemple Documents\favorites-sorter). Ne supprime pas le dossier ensuite : le navigateur charge l'extension depuis celui-ci.
  2. Ouvre chrome://extensions (sur Edge : edge://extensions).
  3. Active le Mode développeur (en haut à droite).
  4. Clique sur Charger l'extension non empaquetée et choisis le dossier qui contient manifest.json.
  5. Ouvre tiktok.com et connecte-toi : un bouton flottant ⇄ Trier mes favoris apparaît. Clique dessus, puis sur « Importer depuis mon profil TikTok ».

Bon à savoir

  • Chrome peut afficher un message sur les extensions en mode développeur au démarrage. Ferme-le pour garder l'extension, ou réinstalle-la depuis le Web Store quand elle y sera.
  • Les mises à jour sont manuelles : télécharge le nouveau .zip, remplace le contenu du dossier, clique sur la flèche de rechargement (↻) de l'extension, puis recharge tiktok.com.
  • Pour le Pro, achète la licence sur la page d'accueil et colle la clé dans l'extension, réglages → Licence.
  • Tes données restent dans le navigateur. Supprimer l'extension les efface.

L'extension automatise des actions sur ton compte TikTok, ce qui peut aller à l'encontre des conditions d'utilisation de TikTok. TikTok peut limiter, suspendre ou bannir un compte. Tu l'utilises à tes propres risques. Non affilié à TikTok.
