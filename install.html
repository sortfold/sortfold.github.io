Install Favorites Cleaner for TikTok

Works in Chrome, Edge and Brave on a computer.

Easiest: one click from the Chrome Web Store. Updates are automatic.

＋ Add to Chrome – it's free

Or install it manually (about 2 minutes)

⬇ Download (.zip)

  1. Unzip the file you just downloaded.Right-click it → Extract all (or Extract to “favorites-sorter/” if you use 7-Zip or WinRAR). Put the new favorites-sorter folder somewhere you will keep it, for example in Documents. Do not delete it later: the browser runs the extension from this folder.
  2. Open the extensions page.In the address bar of Chrome, type chrome://extensions and press Enter. (Edge: edge://extensions.)
  3. Turn on “Developer mode”.It is a switch at the top right of that page.
  4. Click “Load unpacked”A window opens: select the favorites-sorter folder you just unzipped, then click Select folder. Favorites Cleaner for TikTok now appears in your list.
  5. Open TikTok.Go to tiktok.com and sign in. A red button ⇄ Sort my favorites appears at the bottom right. Click it, then Import from my TikTok profile.

Good to know

  • Settings: the ⚙ Settings button at the top of the panel. Language, swipe direction and speed are there.
  • Language: the panel follows the language of TikTok. Use the EN / FR button at the top right of the panel to switch.
  • Free plan: 200 removals per day. Pro: unlimited, one-time payment, on the home page. After buying, click ⭐ Go Pro at the top of the panel and paste your key.
  • Chrome may show a warning at startup about extensions in developer mode. This is normal for a manual install: just close it.

It does not work?

“Manifest file is missing or unreadable”You selected the wrong folder. Select the favorites-sorter folder itself (the one you see manifest.json in when you open it), not the .zip file and not a folder around it.

I do not see the red button on TikTok.Reload the TikTok page (F5). Check on chrome://extensions that Favorites Cleaner for TikTok is switched on.

The panel says I am not signed in.Sign in to TikTok first, then open your own profile once.

How do I update without losing my sorting?Unzip the new .zip into the same folder (replace the files), then on chrome://extensions click the round arrow ↻ on the Favorites Cleaner for TikTok card and reload TikTok. Your data is kept. Do not click Remove and do not load a different folder: that starts from zero.

How do I remove it?First make a backup: in the panel, Activity tab → Export my data (free). Then on chrome://extensions, click Remove: your sorting is deleted with it. To get it back later, install again and use Restore a backup.

I moved or reinstalled and my sorting is gone.The extension keeps your data inside itself, so a new folder or a fresh install starts empty. If you made a backup, open Activity → Restore a backup and pick the file (tiktok-swipe-sauvegarde-….json).

Installer Nettoyeur de favoris pour TikTok

Fonctionne sur ordinateur avec Chrome, Edge et Brave.

Le plus simple : en un clic depuis le Chrome Web Store. Les mises à jour sont automatiques.

＋ Ajouter à Chrome – c'est gratuit

Ou installe-la à la main (environ 2 minutes)

⬇ Télécharger (.zip)

  1. Décompresse le fichier téléchargé.Clic droit dessus → Extraire tout (ou Extraire vers « favorites-sorter/ » si tu utilises 7-Zip ou WinRAR). Mets le nouveau dossier favorites-sorter à un endroit où il restera, par exemple dans Documents. Ne le supprime pas ensuite : le navigateur fait tourner l'extension depuis ce dossier.
  2. Ouvre la page des extensions.Dans la barre d'adresse de Chrome, tape chrome://extensions puis Entrée. (Edge : edge://extensions.)
  3. Active le « Mode développeur ».C'est un interrupteur en haut à droite de cette page.
  4. Clique sur « Charger l'extension non empaquetée »Une fenêtre s'ouvre : sélectionne le dossier favorites-sorter que tu viens de décompresser, puis clique sur Sélectionner un dossier. Nettoyeur de favoris pour TikTok apparaît alors dans ta liste.
  5. Ouvre TikTok.Va sur tiktok.com et connecte-toi. Un bouton rouge ⇄ Trier mes favoris apparaît en bas à droite. Clique dessus, puis sur Importer depuis mon profil TikTok.

Bon à savoir

  • Réglages : le bouton ⚙ Réglages en haut du panneau. La langue, le sens des gestes et la vitesse y sont.
  • Langue : le panneau suit la langue de TikTok. Le bouton EN / FR en haut à droite du panneau permet d'en changer.
  • Version gratuite : 200 retraits par jour. Pro : illimité, paiement unique, sur la page d'accueil. Après l'achat, clique sur ⭐ Passer en Pro en haut du panneau et colle ta clé.
  • Chrome peut afficher un avertissement au démarrage sur les extensions en mode développeur. C'est normal pour une installation manuelle : ferme-le simplement.

Ça ne marche pas ?

« Le fichier manifeste est manquant ou illisible »Tu as sélectionné le mauvais dossier. Sélectionne le dossier favorites-sorter lui-même (celui où tu vois manifest.json quand tu l'ouvres), pas le fichier .zip ni un dossier qui l'entoure.

Je ne vois pas le bouton rouge sur TikTok.Recharge la page TikTok (F5). Vérifie sur chrome://extensions que Nettoyeur de favoris pour TikTok est activé.

Le panneau dit que je ne suis pas connecté.Connecte-toi d'abord à TikTok, puis ouvre une fois ton propre profil.

Comment mettre à jour sans perdre mon tri ?Décompresse le nouveau .zip dans le même dossier (remplace les fichiers), puis sur chrome://extensions clique sur la flèche ronde ↻ de la carte Nettoyeur de favoris pour TikTok et recharge TikTok. Tes données sont conservées. Ne clique pas sur Supprimer et ne charge pas un autre dossier : ça repart de zéro.

Comment le supprimer ?Fais d'abord une sauvegarde : dans le panneau, onglet Suivi → Exporter mes données (gratuit). Puis sur chrome://extensions, clique sur Supprimer : ton tri est supprimé avec. Pour le retrouver plus tard, réinstalle et utilise Restaurer une sauvegarde.

J'ai déplacé ou réinstallé et mon tri a disparu.L'extension garde tes données à l'intérieur d'elle-même : un nouveau dossier ou une nouvelle installation repart de zéro. Si tu as une sauvegarde, ouvre Suivi → Restaurer une sauvegarde et choisis le fichier (tiktok-swipe-sauvegarde-….json).
